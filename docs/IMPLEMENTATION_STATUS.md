## 与原规划的实施差异

- 保留 Astro + TypeScript、Python、GitHub Pages 和手动季度发布。数据客户端直接使用官方 API v2 的匿名 HTTPS 请求（Python 标准库），未使用 openreview-py；数据合同用 JSON Schema/jsonschema，未使用 Pydantic。这些是实现差异，不宣称已完全按规划的所有库名实现。
- 为避免把不完整来源作为正式数据，本工程当前 production gate 要求论坛抓取也完整；局部来源仍可用于私下排查，但不通过生产门禁。原规划允许披露为 observed_sample 的部分论坛发布路径尚未开放。
- 首轮交付保存在本地 implementation 分支并提供压缩包；后续用户指定 `yuhanlydia/OpenJudge` 作为代码仓库。网站仍未部署，数据门禁不变。
- 未开发可选 MCP、在线模型 API、数据库、登录或定时任务。费用预算仍为 0。
